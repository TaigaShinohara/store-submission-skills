# ストア別要件マトリクス

使い方：数字は変わる前提で扱う。案件ごとに公式ドキュメントで再確認し、確認日とURLを案件のレポートに書く。ここにある数字は 2026-11-13 時点で公式案内や実務資料から確認した目安であり、そのまま提出判定に使わない。

## 全ストア共通で先に揃えるもの

- プライバシーポリシーの公開URL（データ収集が無いアプリでも求めるストアが多い）
- サポート連絡先とサポートURL（実際に届くもの）
- データの棚卸し表（収集する種類、目的、第三者への共有、保存期間、削除手段。SDK分を含む）
- 権限と機能の対応表（権限1つにつき理由1文）
- 年齢レーティング質問への回答素材（暴力、性的表現、賭博、ユーザー生成コンテンツ、位置情報、課金の有無）
- 審査用アカウントと操作説明（ログイン必須の場合）
- 著作権と商標の確認（アプリ名、アイコン、スクリーンショット内の他者素材）

## Apple App Store（iOS / iPadOS / macOS / watchOS / tvOS / visionOS）

- 窓口：App Store Connect。Apple Developer Program 年会費が必要（目安 99 USD/年）。
- 提出物：Xcode でビルドした署名済みビルド。最低SDKは毎年春に上がる（2026-04-28 以降は Xcode 26 / iOS 26 SDK 系が下限という案内を確認済み。案件ごとに再確認する）。
- 必須の申告：App Privacy（プライバシーの栄養ラベル）、PrivacyInfo.xcprivacy（プライバシーマニフェスト、要理由APIとSDK分）、年齢レーティング質問、輸出コンプライアンス、App Review Information（連絡先、デモアカウント、メモ）。
- スクリーンショット：iPhone は 6.9インチ級（1320x2868 など）が基準で小サイズへ自動縮小。iPad対応なら 13インチ級（2064x2752 など）が必須。1デバイス区分につき1から10枚、PNG/JPEG、透明なし。macOS は 1280x800 系、watchOS は対象ウォッチの寸法。寸法は案件ごとに公式の Screenshot specifications で再確認する。
- 課金：デジタル商品は原則アプリ内課金。外部決済誘導には地域ごとの例外と資格があるため、案件ごとに確認する。
- 落ちやすい箇所：2.1 クラッシュと未完成、2.3 メタデータ不正確、3.1 課金、4.2 最小機能、4.3 量産とコピー、5.1.1 データ収集と同意、サインインとアカウント削除（アカウント作成があるアプリはアプリ内削除導線が必須）。
- Mac の代替経路：Mac App Store を使わない場合は Developer ID 署名と公証（notarization）が別経路になる。ストア提出とは判定を分ける。

## Google Play（Android / Wear OS）

- 窓口：Google Play Console。開発者登録は一回払い（目安 25 USD）。本人確認が必須。
- 提出物：AAB（Android App Bundle）。APK単体は新規提出不可。Play App Signing が前提。
- 技術の下限：対象APIレベルは毎年上がる（2026-08-31 以降、新規と更新は API 36 / Android 16 が下限という案内を確認済み。Wear OS などフォームファクタで下限が違うため案件ごとに再確認する）。
- 必須の申告：Data safety フォーム（収集、共有、暗号化、削除請求）、コンテンツレーティング（IARC）、ターゲットオーディエンス、広告の有無、プライバシーポリシーURL、権限の申告（写真・動画、位置情報、フォアグラウンドサービス等は用途宣言が要る場合がある）。
- 特殊条件：2023-11-13 以降に作った個人アカウントは、本番公開の前にクローズドテスト（12人以上、14日間継続）が必須。組織アカウントは対象外の場合があるためアカウント種別を先に確認する。
- アカウント削除とデータ削除の導線：アカウント作成があるアプリは、アプリ内削除と Web からのデータ削除請求導線の両方を求められる。

## Chrome Web Store（Chrome拡張機能）

- 窓口：Chrome Web Store Developer Dashboard。登録料は一回払い（目安 5 USD）。2段階認証が必須。
- 提出物：manifest.json を ZIP のルートに置いた ZIP。Manifest V3 が必須。リモートコード実行は禁止。
- 必須の申告：Privacy practices タブで、単一目的の説明、権限1つごとの正当化、リモートコード宣言、データ利用の申告、プライバシーポリシーURL（ユーザーデータを扱う場合）。
- 素材：名前 75文字まで、概要 132文字まで、スクリーンショット 1280x800（または 640x400）を1から5枚、ストアアイコン 128x128、小プロモーションタイル 440x280 は任意。
- 落ちやすい箇所：広すぎるホスト権限（<all_urls> 等）の理由不足、使っていない権限、単一目的からの逸脱、アフィリエイトの事前開示なし（2025年ポリシー）。

## Microsoft Store（Windows）

- 窓口：Partner Center。名前の予約が提出の前提。登録料は 2025年以降の新フローで無料化された案内があるため、登録時に再確認する。本人確認（政府ID等）がある。
- 提出物：MSIX / MSIXUpload 等。EXE / MSI インストーラ形式の提出経路もあり、その場合は署名の扱いが違うため経路ごとに確認する。
- 必須の申告：カテゴリ、年齢レーティング（IARC質問）、プライバシーポリシーURL（個人情報にアクセスするアプリ）、システム要件、サポート連絡先。
- 素材：説明 10,000文字まで、スクリーンショットはデスクトップで 1366x768 以上を少なくとも1枚（最大10枚、4枚以上推奨）、ストアロゴ 300x300、検索語は最大7件。
- 審査：認証（certification）は数時間から3営業日程度が目安。WACK 等の自動検証で落ちる場合はパッケージ側の修正が要る。

## その他のストア（同じ型で追加する）

- Firefox Add-ons と Edge Add-ons：拡張機能系。Chrome版の素材を流用できる場合が多いが、Manifest対応と権限審査の基準が違うため、流用可否を項目ごとに確認する。
- Samsung Galaxy Store と Amazon Appstore：Android系。AAB / APK の可否、独自のコンテンツ申告と決済ルールを個別に確認する。
- Steam：ゲーム系。提出物はビルドとストアページ素材で、審査はページ審査とビルド審査の2段。パートナー登録料はタイトルごとにかかる。
- ウォッチ単体：Apple Watch と Wear OS は原則として母艦アプリの提出に含まれる。単体アプリとして出す場合も、提出窓口は同じで、スクリーンショットと動作要件がウォッチ専用になる。
