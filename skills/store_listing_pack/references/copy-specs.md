# 文案の仕様

使い方：2026-11-13 時点の目安。案件ごとに公式仕様で再確認し、変わっていたらこのファイルも直す。文字数は全角・半角を問わずストアの数え方に従うため、検証では実際に数える。

## マスター原稿に用意するもの

- アプリ名（正式名称）
- 短い紹介（1文、約30から80文字の核）
- 機能の説明（箇条書き3から5点、実態のみ）
- 長い説明（想定読者、使う場面、できること、できないこと、料金の考え方）
- キーワード候補（重複なし、他社の商標を入れない）
- 更新内容（その版で変わったことだけ）
- サポート文面とプライバシー要約

## ストア別の主な上限（目安）

- Apple App Store：名前 30文字、サブタイトル 30文字、プロモーション文 170文字、説明 4,000文字、キーワード 100文字（カンマ区切り合計）、新機能 4,000文字。
- Google Play：アプリ名 30文字、簡単な説明 80文字、詳しい説明 4,000文字。フィーチャーグラフィックが必須級の素材になる。
- Chrome Web Store：名前 75文字、概要 132文字、詳しい説明はダッシュボードの上限に従う。単一目的の説明を別途用意する。
- Microsoft Store：説明 10,000文字、検索語は最大7件。各言語ごとに説明とスクリーンショットが要る場合がある。

## 文案のルール

- 1つの主張を全ストアでそろえる。ストアごとに違う機能をうたわない。
- 未実装、地域限定、将来予定の機能は、現在の機能として書かない。
- 価格、無料範囲、対応OSは実物と一致させる。
- 他社の製品名や商標を、比較やキーワード目的で入れない。
- レーティングや受賞などの表示は、出典を示せる場合だけ使う。
